# Churn_Customer_Dashboard

1. Project Title

Power BI End-to-End Churn Analysis Dashboard

2. Short Description / Purpose

This project shows how to build a complete churn analysis dashboard using Power BI. The goal is to take raw business data, analyze customer churn behavior, and present key insights visually in a dashboard that helps stakeholders understand what drives customer attrition.

3. Tech Stack

-The key technologies used in this project include:

-Microsoft Power BI Desktop – for building the dashboard

-Power Query (M Language) – for data transformation

-DAX (Data Analysis Expressions) – for calculated measures and metrics

-SQL Server – used for storing and querying the processed data before loading into Power BI

4. Data Source

The data for this churn analysis project comes from a SQL Server database where raw business records related to customers, transactions, and account activity are stored. The workflow typically extracts and prepares these tables, then loads them into Power BI for modeling and visualization.

5. Features / Highlights

-End-to-end churn analysis dashboard created with Power BI

-Data extraction and ETL from SQL Server

-Data cleaning and transformation using Power Query

-Customer segmentation and churn calculation using DAX

-Interactive charts such as trend lines, bar charts, and scorecards

-Filters and slicers to explore churn by time period, customer segment, or product

-Clear visuals to identify patterns and drivers of churn

-Dashboard designed for business insights and decision-making
